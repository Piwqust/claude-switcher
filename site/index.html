Read the security notes →

  • No network access

    There is no networking code at all: no telemetry, no update check.

  • Sign-ins are never touched

    Tokens, cookies and passwords are not read or copied. Each account signs in by itself.

  • Claude is not modified

    Only standard Electron and Windows mechanisms. No patching, no proxy.

  • No admin rights

    Everything goes into your user profile. Releases are built by GitHub Actions, with SHA-256 checksums.

One app, a folder per account

Claude Desktop keeps its sign-in, chats and settings in one data folder. Pointed at another folder, it is another account, running next to the first.

Questions

Does it change my main Claude account?

No. Your main account starts the usual way and keeps auto update and claude:// links. Extra accounts live in their own folders in %LOCALAPPDATA%\ClaudeProfiles.

What do the accounts share?

Claude Code’s settings, plugins, MCP servers and session history live in your user folder, so every account uses the same set. claude:// links and Claude in Chrome go to the main account, and Claude’s own quick-entry hotkey goes to whichever copy started first.

How much memory does each account use?

Each open account is a full copy of Claude Desktop, so budget roughly one Claude per window. The switcher itself uses about 16 MB.

How do I update?

Run the new version. Your accounts and settings are kept. Claude itself updates once for every account; windows already open stay on the old version until restarted.

I used Claude Code Desktop Switcher. Will my setup carry over?

Yes. This is a C++ rewrite of the PowerShell script by @PriyanshuGeTRekT that worked out the idea. The profile folders are the same, so accounts, names, colours and shortcuts carry straight over.

Is this an official Anthropic app?

No. It is an independent open-source project, not affiliated with, endorsed by or supported by Anthropic. Using several accounts is subject to Anthropic’s terms.
